# 🚀 Projeto Sonar

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica com o objetivo de criar um sistema de sonar capaz de detectar objetos e identificar sua localização em relação ao sensor.

O sistema realiza uma varredura utilizando um sensor ultrassônico e apresenta informações sobre a presença de um objeto, sua distância e o ângulo em que ele foi detectado.

## 🔎 Como funciona

O sistema utiliza um sensor ultrassônico HC-SR04 conectado a um Arduino.

O sensor é movimentado por meio de um servo motor, realizando uma varredura em diferentes ângulos.

Durante a varredura, o sistema identifica:

- ✅ Se existe um objeto;
- 📏 A distância aproximada até o objeto;
- 📐 O ângulo em que o objeto foi localizado.

As informações são enviadas para o computador e apresentadas visualmente, permitindo acompanhar a posição dos objetos detectados.

## 🛠️ Tecnologias e componentes

- Arduino
- Sensor ultrassônico HC-SR04
- Servo motor
- Linguagem C
- Programação
- Eletrônica
